# 《星烬契约》角色美术方向 v0.5

## 总体风格

定位为「东方幻想 × 星轨科技 × 轻科幻灵能」的 2D 卡牌 RPG。避免直接复刻任何现有玄幻 IP 的服饰、武器、势力或专有概念。

- 角色比例：偏成年/青年英雄，不做幼态 Q 版作为主卡面。
- 卡面构图：半身到 3/4 身，角色占画面 65% 左右，背景用阵营符号和能量轨迹。
- 材质：布料、轻甲、星烬晶体、半透明能量装置混合。
- 光效：角色主体清晰，技能色作为第二光源，不使用满屏特效掩盖轮廓。
- SSR：完整光环、复杂武器、双层粒子背景。
- SR：保留明显阵营纹样，特效较少。
- R：更偏实战装备与普通契灵者，轮廓简洁。

## 五大阵营视觉语言

- 曜庭：金 / 靛蓝，星轨、几何环、折光金属。
- 赤环：赤红 / 橙金，环火、羽片、热流纹。
- 镜海：青蓝 / 冰白，水镜、潮纹、透明护层。
- 青原：草绿 / 木棕，藤纹、叶片、岩木混合装备。
- 灰境：灰紫 / 黑银，雾、残月、断裂阴影与低饱和金属。

## 首批重点角色

### 夜岚 · SSR · 曜庭强攻
银黑短发、修长折光长刀、非对称深色轻甲；背后是断裂的金色星轨环。气质冷静、压迫感强，是主视觉男性角色。

### 绯歌 · SSR · 赤环术式
深红长发、环刃法器悬浮在手臂两侧，服装采用黑红短斗篷与热流纹金属饰片；技能时形成赤色火环与羽片。

### 白砚 · SSR · 镜海辅助
雪白长发、冷青色长衣与透明镜片法器，整体安静、理性；技能以水镜反射与潮汐光纹表现，不做传统法杖法师。

### 青禾 · SR · 青原治疗
墨绿双辫、轻旅行装、藤木药杖与腰间药囊，视觉亲和但不幼态；治疗效果是青绿色萤光嫩芽。

### 司南 · SR · 曜庭控制
蓝黑高马尾，腰后悬浮磁轨圆盘，战斗时展开几何星盘；更偏技术官/战术师形象。

### 逐影 · SR · 灰境刺击
灰紫长发、窄身暗甲与影刃，轮廓干净、动作偏低姿态，身后是被切开的黑雾月牙。
