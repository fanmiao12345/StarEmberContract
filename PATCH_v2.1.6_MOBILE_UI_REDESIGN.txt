星烬契约 v2.1.6 · Mobile UI Redesign

本版本基于 v2.1.5 Gameplay Hardening，只重构 Web 客户端界面与信息架构，不改变 SAVE_VERSION、CloudBase 数据结构或玩法数值。

主要变化：
1. 首页重做为角色大厅：中央“今日星轨”主卡、继续主线主按钮、扫荡/培养次按钮、每日/每周进度卡。
2. 顶部资源栏收纳为核心三资源，点击可展开查看星铁、锻造尘、觉醒核等完整库存。
3. 底部导航收敛为：首页 / 探索 / 编队 / 活动 / 事务所，共 5 个大触控入口。
4. 契约、邮件、福利、商店改为首页快捷入口；其余二级系统可通过快捷菜单访问。
5. 探索、编队、养成、契约、活动、事务所统一为卡片式层级与大按钮，减少长页面堆叠。
6. 子页面顶部统一“返回首页 + 当前模块 + 快捷”结构。
7. 移动端按钮高度、间距、底部操作区和安全区重新优化。
8. 保留 v2.1.5 全部玩法加固规则及旧存档兼容。
